# Spec: MathDinoSpecies (Epic39)

## Overview / Goal

Three new dino species for the three math journeys, drawn in the same style as the existing T-Rex, Triceratops, long-neck, and pterosaur: Stegosaurus, Ankylosaurus, and Parasaurolophus. Each species has an egg, five growth stages, idle animations, and evolution scenes.

## Decisions

| Topic | Decision | Justification |
|-------|----------|---------------|
| Species | Stegosaurus (back plates), Ankylosaurus (armour, club tail), Parasaurolophus (head crest) | Clearly different silhouettes, distinct from the reading dinos |
| Display names | "Stegosaurus", "Panzersaurier", "Kammsaurier" | Child-friendly German names, like "Langhals" and "Flugsaurier" |
| Pictures | 6 SVGs per species: `stage-0.svg` (egg) to `stage-5.svg` (fully grown) | Same pipeline as the reading dinos (MathJourneys maps 7 levels to 5 stages) |
| Stage content | 0 egg, 1 hatched baby, 2 first steps, 3 counting pebbles / first catch, 4 young dino, 5 fully grown | Follows the established story; stage 3 gets a small math touch |
| Colours | Stegosaurus green-orange, Ankylosaurus sand-brown, Parasaurolophus blue-violet; egg colour matches the species | Recognizable in the valley next to the four reading dinos |
| Animations | Idle animations via CSS like the existing species (breathing, blinking, tail wag); species-specific accent: plates wobble, club tail swings, crest glows softly | Same effort and style as NewDinoSpecies |
| Accessories | The existing accessory anchors (head, eyes, neck) are positioned per species and stage | Wardrobe works for every dino |

## Technical Details

- Files: `assets/svg/dino/stegosaurus/stage-0..5.svg`, `assets/svg/dino/ankylosaurus/stage-0..5.svg`, `assets/svg/dino/parasaurolophus/stage-0..5.svg`.
- `js/components/dino.js` preloads all species of `JOURNEYS`, so the new species are picked up automatically once they are listed (MathJourneys).
- Accessory anchor positions per species and stage are added where the existing species define them (`css/components/dino.css`, modifiers `dino--stegosaurus`, `dino--ankylosaurus`, `dino--parasaurolophus`).
- Evolution scenes (`evolutionScene.js`) use the new stage pictures; texts per stage for the math species (e.g. stage 3: "<Name> zählt seine ersten Steine!").
- Valley: the new species appear in the "Rechen-Dinos" group (SubjectSelection).
- The SVGs contain no text and no emojis; they use the same viewBox and stroke width as the existing species.

## Acceptance Criteria

- Each of the three species has six stage pictures in the style of the existing dinos.
- The species are clearly distinguishable from each other and from the four reading dinos in the valley.
- Idle animations run for all stages from 1 to 5; the egg wobbles like the existing eggs.
- Accessories sit correctly on head, eyes, and neck for all stages of the new species.
- Evolution scenes show the correct before/after pictures and species-specific texts.
- A test checks that every species in `JOURNEYS` has stage files 0-5.

## Open Risks / Assumptions

- Drawing 18 SVGs is the largest effort of this epic; the existing species serve as templates for proportions and line style.
- Assumption: the math touch of stage 3 is optional decoration (pebbles next to the dino), not a new mechanic.

## Implementation Notes

- The 18 SVGs are generated by `scripts/generateMathDinos.js` with the same stage transforms as the reading dinos.
